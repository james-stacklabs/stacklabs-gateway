# StackLabs LLC — Public Web Gateway

Official public presence for **StackLabs LLC** ([stacklabsllc.com](https://www.stacklabsllc.com)).

## Architecture
- **Edge Deployment**: Cloudflare Workers with Static Assets (CDN Cache-First)
- **CI/CD**: GitOps continuous deployment on push to `main`
- **Zero-Retention Core**: Sovereign enterprise edge gateway decoupling public traffic from internal clusters
- **Assets**:
  - `index.html`: Enterprise landing portal & Statutory Zero-Retention briefing
  - `homestead.html`: Grassroots host and node sponsorship portal
  - `stacklabs_model_s_architecture_briefing.mp4`: Executive video briefing
